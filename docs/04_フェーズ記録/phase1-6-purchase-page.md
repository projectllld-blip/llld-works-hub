# v1.6 購入ページ

## 目的

決済実装に入る前に、マーケットの商品を「確認してから利用開始 / 購入確認する」ための購入ページMVPを整える。

今回のv1.6は、支払い処理、購入履歴、正式な利用権限付与ではない。

## 実装範囲

- `purchase-confirm.html` を、無料 / β版 / 買い切り / サブスクの確認ページとして使う。
- 無料アプリは「利用開始確認」から進む。
- β版は「β版利用確認」から進む。
- 買い切り / サブスクは「購入確認」から進むが、決済未実装中はポータル追加や利用開始を行わない。
- 準備中 / 開発中の商品は、購入・利用開始させず先行案内や相談導線へ流す。
- 開発相談商品は、購入ではなく開発相談導線へ流す。
- 確認完了後は、同じブラウザセッション内で `portal.html` に一時追加する。
- 任意サポートとして、初期設定サポート、使い方説明、カスタマイズ相談、導入代行の希望を選べる。

## 今回やっていないこと

- 決済実装
- 購入履歴実装
- 正式な契約状態管理
- `app_instances` への正式追加
- `app_data` 変更
- `company_accounts` 変更
- `plan_status` 変更
- Supabase migration / RLS変更
- Supabase Dashboard操作
- 本物管理者画面
- 管理者画面からの商品 / 料金 / CTA編集

## 注意

確認後のポータル追加は、無料 / β版だけに許可する `sessionStorage` による一時表示MVPである。

有料 / サブスクは、決済未実装中は購入内容の確認だけを行い、`sessionStorage` への仮追加、ポータル表示、利用中アプリ表示は行わない。

正式な購入後の利用開始、利用中アプリ反映、購入履歴、決済連携は後続フェーズで扱う。

- 商品名
- 商品説明
- カテゴリ
- 料金形態
- 価格

## v1.6での一時的な正本

v1.6では、商品状態とCTAの正本は以下に残る。

- `data/contents.json`
- `assets/js/marketPages.js`
- `assets/js/purchaseConfirmPage.js`

これは本番運用の最終形ではない。

料金・CTAを管理者画面から変更する機能は、DB / RLS / 管理者権限の設計後に扱う。

`app_add_requests` は購入者導線には使わない。v1.6の購入 / 利用開始確認でも、`app_add_requests` への保存や読込は行わない。

## `portal.html` の変更範囲

今回の `portal.html` 変更は、`purchase-confirm.html` で確認完了した無料 / β版の商品を同一ブラウザセッション内で一時表示するときのラベル調整に限定する。

- `sessionStorage` の一時追加データに含まれる `portalStatusLabel` を表示する。
- `portalStatusLabel` がない場合は、価格種別 / アクション種別から「β版利用開始済み」「利用開始済み」を表示する。
- 古いセッションデータを含め、有料 / サブスクの `priceType` や `purchase` actionはポータル表示対象から除外する。
- `portal_state`、`app_data`、Supabase保存、RLS、既存ポータル保存処理には触っていない。
- 既存のポータル保存・表示の正本は引き続き `app_data.data_type = portal_state` と localStorageキャッシュであり、v1.6の一時追加表示とは分離する。

## `purchase-confirm.html` の扱い

`purchase-confirm.html` はPR #46までに作成済みの既存HTMLを使用する。

今回のv1.6ブランチでは、HTML本体ではなく `assets/js/purchaseConfirmPage.js` を更新し、無料 / β版 / 買い切り / サブスク / 開発中の確認フロー、任意サポート選択、ポータル一時追加可否を整理した。

## 種別ごとの扱い

- 無料アプリ: 利用開始確認後、`sessionStorage` 上の仮追加表示を許可する。
- β版アプリ: β版利用確認後、`sessionStorage` 上の仮追加表示を許可する。
- 有料アプリ: 購入確認のみ。決済未実装中は `sessionStorage` に追加せず、ポータルや利用中アプリには表示しない。
- サブスクアプリ: 購入確認のみ。決済未実装中は `sessionStorage` に追加せず、ポータルや利用中アプリには表示しない。
- 開発中 / 準備中: 購入・利用開始不可。先行案内または相談導線のみ。

有料 / サブスクは、正式な購入・決済が完了した後、または運営側の明示的な利用開始処理後に利用可能にする。

有料化前に無料で使わせたいアプリは、有料ではなく、無料 / β版 / 無料トライアルとして分類する。
