# v1.6c 管理者mock画面：商品/料金/表示状態確認

## Phase

v1.6c 管理者mock画面：商品/料金/表示状態確認

## 状態

実装完了。人間ブラウザ確認待ち。

## 目的

v1.6bで整理した商品・料金・CTA設定を、将来の管理者画面でどのように確認するかを、実DB接続なしの固定mockで確認できるようにする。

今回は本物の管理者画面ではない。商品、料金、CTA、表示状態、サポート設定、購入後の反映先 `app_key`、異常状態を画面上で確認するためのmock UIである。

## 実装した内容

- `admin.html` に「商品・料金・CTA確認 mock」セクションを追加。
- `assets/js/adminMockPage.js` に固定の商品mockデータを追加。
- 商品ごとに以下を表示。
  - 商品名
  - 価格
  - 無料 / β版 / 買い切り / サブスク / 開発相談 / 開発中
  - 表示状態
  - CTA種別
  - カテゴリ
  - サポート対象
  - 初期設定サポート有無
  - 購入後の反映先 `app_key`
  - サムネイル有無
  - 商品説明有無
- 異常状態mockとして以下を表示。
  - 価格未設定
  - CTA未設定
  - `app_key` なし
  - サムネイルなし
  - 商品説明なし

## 実DBに接続していないこと

今回のv1.6cは固定mockデータのみを表示する。

- Supabaseには接続しない。
- Authには接続しない。
- 企業横断データ取得はしない。
- `data/contents.json` は変更しない。
- 商品・料金・CTAをDB保存しない。
- 管理者画面から料金や表示状態を変更しない。
- `apps` / `app_instances` / `app_data` / `company_accounts` / `plan_status` は変更しない。

## 今回扱わないこと

- 本物管理者画面。
- 商品マスタ / 料金マスタDB。
- 管理者ロール。
- 管理者RLS。
- 管理者画面からのDB編集。
- 決済。
- 購入履歴。
- 購入後の正式な `app_instances` 反映。
- `data/contents.json` の正規化。

## 次フェーズへの引き継ぎ

次の本線候補は `v1.7 購入後の利用開始・利用中アプリ反映`。

v1.7では、無料 / β版の確認後に、どのように正式な利用中アプリへ反映するかを整理する。`app_instances` 反映、DB / RLS、利用停止状態、購入済み・利用可能状態の分離は、人間確認を挟んで設計する。

本物管理者画面からの商品・料金・掲載状態編集は v2.x 以降に分離する。
