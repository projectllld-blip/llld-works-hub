# v1.x Portal UIUX Consolidation

## 目的

`portal.html` を今後の社内ポータル本体として扱い、旧入口だった `index.html` の社内ツールポータル表示を廃止する。

あわせて、GitHub Pages公開版で確認された以下のUIUX課題を整理する。

- 旧社内ツールポータルと新ポータルの入口分離による混乱。
- ヘッダー右側ボタンの文字位置ずれ。
- 新着投稿ボックス内の余白の詰まり。
- アプリカードのサイズ・サムネイル表示のばらつき。
- アプリカードのサムネイル品質。

## 実施内容

- `index.html` を旧ポータル本体ではなく `portal.html` への入口に変更。
- JS無効環境でも `portal.html` へ移動できる手動リンクを設置。
- 画面表示上の「社内ツールポータル」は廃止し、「社内ポータル」に統一。
- `portal.html` のヘッダー右側ボタンを `inline-flex` で上下左右中央揃えに統一。
- `新着投稿` の投稿カード間余白、カード内padding、ページネーション余白を調整。
- アプリカードを同じカード構造・高さ・サムネイル比率で表示するよう調整。
- 既存の `assets/thumbnails/*-card.svg` を `portal.html` の実カード表示へ紐付け。

## 触っていない範囲

- Supabase設定。
- RLS。
- migration。
- Auth。
- `company_accounts` / `app_instances` / `app_data`。
- 決済、購入、利用開始処理。

## 人間確認が必要なこと

- GitHub Pages公開版で `/` が `portal.html` 入口として機能すること。
- PC / iPad / スマホでヘッダー右側ボタンの文字が中央に見えること。
- `新着投稿` の投稿カードとページネーションの余白が自然に見えること。
- 最近使ったもの / お気に入りアプリ / 購入済み相当カードのサイズ感が揃っていること。
- 既存アプリリンクが壊れていないこと。
