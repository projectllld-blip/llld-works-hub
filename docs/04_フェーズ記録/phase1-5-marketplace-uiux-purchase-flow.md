# v1.5 Marketplace UIUX / Purchase Flow Consolidation

## 目的

`marketplace.html` を、販売前の確認導線として迷わず使える状態に整理する。

今回の目的は、決済実装ではなく、以下の区別を画面上で分かるようにすること。

- マーケットで探す
- 詳細を見る
- 無料 / β版 / 有料のいずれも確認画面を通す
- 確認後、ポータルに一時追加して確認できる
- 既存アプリを開く場合は別タブで開く
- 開発が必要なものは購入ではなく開発要望 / 相談へ流す

## 実装したこと

- `marketplace.html` のマーケットカード表示を、768px以上は4列、767px以下は2列に整理した。
- 無料、β版、有料の商品CTAを `purchase-confirm.html` へ統一した。
- `purchase-confirm.html` を追加し、購入 / 利用開始前に内容、価格、状態、提供方法を確認できるようにした。
- 確認後は `sessionStorage` に一時追加し、同じブラウザセッション内の `portal.html` の購入済みエリアに表示する。
- 既存アプリを開く導線は `target="_blank"` / `rel="noopener"` を付け、別タブで開くようにした。
- 開発相談系は購入確認に流さず、開発要望 / 相談フォームへ誘導する。
- マーケット下部に「ご意見ボックス」を追加し、「こんなツールが欲しい」を開発要望として送る導線にした。

## 注意

今回のポータル追加は、販売導線の操作感を確認するための一時的なMVPである。

正式な購入後の利用開始、利用中アプリ反映、購入履歴、決済連携は後続フェーズで扱う。

## 確認結果

- 390px幅: マーケットカード2列、横スクロールなし。
- 768px幅: マーケットカード4列、横スクロールなし。
- 1024px幅: マーケットカード4列、横スクロールなし。
- 1280px幅: マーケットカード4列、横スクロールなし。
- `purchase-confirm.html?item=pdf-tool` で確認後、`portal.html` の購入済みエリア先頭に追加表示されることをローカルで確認。
